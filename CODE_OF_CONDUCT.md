# Community conduct / 社区行为规范

Be respectful, specific, and constructive. Discuss code and behavior rather than attacking people. Harassment, discrimination, threats, deliberate disclosure of private information, and unsolicited advertising are not welcome.

Use synthetic examples and redact personal or organization data. Respect maintainers' and contributors' time. Maintainers may edit, remove, lock, or limit participation in discussions that violate these expectations. Platform abuse can be reported using GitHub's reporting tools; security issues belong in the private channel described in [SECURITY.md](SECURITY.md).

请尊重他人，围绕代码与产品行为提出具体、建设性的意见。不要骚扰、歧视、威胁、泄露隐私或发布无关广告。使用虚构资料复现，保护个人与公司信息，尊重维护者和贡献者的时间。

维护者可以编辑、移除、锁定违规内容或限制参与。平台滥用可使用 GitHub 举报入口，安全问题通过 [SECURITY.md](SECURITY.md) 的私密渠道报告。
