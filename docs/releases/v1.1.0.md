## 简体中文

本版集中修复 Windows 实测中查询饥饿、持续重索引、资料列表不完整和排障信息不足的问题。部门 Embedding API／API Key、随包 Qwen CPU 模型、仅全文模式和已有资料均保留。

- **查询隔离与无界面 MCP：** 五个工具统一委托共享服务；stdio 握手不等待服务，首次调用可自动启动无界面服务。查询使用独立 WAL 只读连接，6 个普通通道之外预留 2 个全文通道。索引繁忙时可返回实际全文结果；维护、通道满、连接失败与超时分别报告。
- **稳定增量更新：** 原生文件事件只处理变化路径／子树，默认每小时兜底核对。已收录文件默认静默 5 分钟再更新，可选择立即、1／5／10 分钟；持续保存合并，任务代际保护后续变更，未变片段保留向量。临时／Agent 缓存补充默认排除，高频变更和过多项目有范围提示。
- **资料页完整性：** 按集合复用规则和目录检测；加载更多后保持已展开数量，刷新请求合并。失败保留原列表并可重试，不显示内部 Electron 异常前缀，也不会把失败当成空库。在线恢复清除旧读连接，避免恢复后显示旧状态。
- **运行状态与真实错误：** 资料页显示任务、文件队列、静默等待、查询通道、原生监听与向量进度。模型错误保留 HTTP 状态、有限正文和请求 ID，凭据脱敏。调用记录区分计算与传输，不能把传输完成当成 Agent 已确认。
- **Windows 与生命周期：** 读取当前用户固定代理和 bypass，模型可选直连，本机通信绕过代理；PAC 脚本暂不执行并明确提示。所有后台工作退出后再释放运行时；保留 Windows Job Object 管理解析／模型子进程。命令行增加 role；桌面、引擎、MCP 与 PE 文件版本使用同一版本源。
- **明确共享：** 新连接必须选择范围；选择自动共享后，后续可共享资料持续纳入。指定项目从空选择开始。已有连接的授权完整保留，不自动扩权或撤权。
- **独立审查修复：** 争用下的记忆提交等待确定结果，相同参数重试复用待确认建议；部分清理后恢复重复文本时避免片段 ID 冲突，写入入口拒绝重复／冲突 ID，防止静默缺块。

### 升级

先从托盘退出旧程序，建议导出备份，再安装本版。程序目录与数据目录独立，可保留现有数据位置。数据库升级为 **schema 3**，保留旧片段、向量、连接令牌与授权；升级后使用 v1.1.0 或更新版本。旧的 MCP 配置仍可使用，无须手动加 role 或重新配置令牌。此前默认五分钟的周期核对迁移为一小时，自定义周期保留。

Windows x64 下载 `.exe`，Intel Mac 下载 `.dmg`；包含本地模型与中英文 OCR，无需命令行。安装包未签名，暂不提供原生 Apple Silicon／ARM Windows 包。静默窗口期间变化中的原文会暂时退出召回，避免返回旧内容；全文就绪不代表向量全部完成。合成回归与云端原生验收不能替代公司实际文件规模、代理、API 和 ZCode 会话验证。

## English

This release addresses query starvation, repeated reindexing, incomplete library lists and misleading diagnostics seen during Windows testing. Organization Embedding APIs/keys, the bundled Qwen CPU model, full-text-only mode and existing libraries remain supported.

- **Isolated queries and headless MCP:** all five tools delegate to a shared daemon. Stdio initialization is independent of daemon readiness; the first tool call can start it without the UI. WAL readers bypass the index writer. Six normal lanes leave two reserved full-text lanes, with distinct maintenance/capacity/connectivity/deadline errors.
- **Quiet-time incremental indexing:** native events reconcile changed paths/subtrees; hourly full scans recover missed events. Existing files wait five quiet minutes by default, configurable to immediate or 1/5/10 minutes. Repeated saves coalesce; job generations retain newer changes, unchanged chunks retain vectors. More temporary/Agent-cache exclusions and high-activity/project-count notices help narrow sources.
- **Complete library lists:** collection rules and directory checks are reused. Expanded pagination survives refresh; reads coalesce. Transient failures keep the previous list and offer retry without exposing Electron's internal error prefix. Restores invalidate old read connections so the UI cannot reuse stale pages.
- **Status and accurate diagnostics:** inspect current tasks, file jobs, quiet waits, query capacity, native watchers and vector progress. Model errors preserve HTTP status, bounded response text and request ID with API-key redaction. Audit computation and transport separately; handoff cannot prove Agent acknowledgement.
- **Windows and lifecycle:** current-user static proxy/bypass settings and per-model direct routing are supported; loopback bypasses proxies. PAC execution is explicitly unsupported. Join workers before runtime teardown; retain Windows Job Object cleanup for parser/model children. Process roles and desktop/engine/MCP/PE versions are consistent.
- **Explicit sharing:** choose the scope when creating a connection. Automatic sharing includes future shareable sources only after selection; selected-project mode starts empty. Existing authorizations are preserved.
- **Independent-review fixes:** contended proposals return definite results; identical retries reuse the pending record. Recovering repeated chunks after partial cleanup avoids ID collisions, and commits reject duplicate/conflicting IDs rather than silently losing chunks.

### Upgrade

Quit the old tray process, export a backup, then install. Program and data locations remain separate. The database advances to **schema 3**, preserving chunks, vectors, client tokens and authorizations; use v1.1.0 or newer afterward. Existing MCP configurations remain valid without manually adding role flags or replacing tokens. The previous default five-minute reconciliation interval migrates to one hour; custom intervals remain.

Use `.exe` for Windows x64 or `.dmg` for Intel Mac. Runtime/model/OCR resources are bundled; no terminal is needed. Installers are unsigned; native Apple Silicon/ARM Windows packages are not included. Changed sources are withheld during quiet time to avoid stale citations; full-text readiness is separate from completed vector indexing. Synthetic/native CI checks do not establish acceptance for a real company's complete file set, proxy, API or ZCode sessions.
