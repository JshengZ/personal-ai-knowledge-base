# Security policy / 安全报告

## Reporting

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/JshengZ/personal-ai-knowledge-base/security/advisories/new). Include the affected version/platform, minimal synthetic reproduction, expected access boundaries, and observed behavior. Never attach real work documents, API keys, backups, or live MCP tokens.

Public issues are appropriate for ordinary bugs. If you are unsure whether an issue exposes private data or bypasses permissions, use the private reporting channel first. Maintainers will assess reports as available; no response-time SLA or bug bounty is currently offered.

The latest published release is the maintenance target. There is currently no LTS policy or automatic update mechanism. Unsigned binaries and pending organization-specific validation are documented in the release notes.

## 中文

漏洞请通过 [GitHub 私密漏洞报告](https://github.com/JshengZ/personal-ai-knowledge-base/security/advisories/new)提交，包含版本、平台、虚构资料的最小复现、预期授权边界与实际行为。不要上传真实工作文件、API Key、备份或有效 Agent 令牌。

普通功能问题可以公开提交 Issue。可能涉及资料泄露或权限绕过的问题优先使用私密渠道。维护者按实际可用时间处理，目前没有响应时间承诺或漏洞奖励计划。

维护目标为最新发布版本，暂不提供 LTS 或在线自动更新。签名与公司环境验证状态会在发布说明中注明。
